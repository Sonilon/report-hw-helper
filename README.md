# ReportWatcher 🔍

Fabric мод для Minecraft 1.20.1, который автоматически мониторит `/reportlist` и уведомляет о подходящих жалобах в чате — без открытия GUI.

## Как работает

1. Каждые N секунд (по умолчанию 30) мод отправляет команду `/reportlist`
2. Когда сервер открывает GUI — мод перехватывает его **незаметно для игрока**
3. Анализирует все свободные репорты (голова зомби) по триггерам
4. Выводит в чат подходящие репорты с полной информацией

## Триггеры срабатывания

Репорт попадает в уведомление если **оба** условия выполнены:

| Условие | Описание |
|---------|----------|
| **Заявитель** | ПЖ (зелёные) > ЛЖ (красные) |
| **Подозреваемый** | Нет доната (цвет ника) **И** ПП = 0 |

**Приоритет:** репорты из первой строки меню (слоты 0–8) помечаются `[ПРИОРИТЕТ]` и идут первыми.

## Команды

| Команда | Действие |
|---------|----------|
| `/rw check` | Запустить проверку прямо сейчас |
| `/rw status` | Показать статус мода и интервал |

## Конфиг

Файл: `.minecraft/config/reportwatcher.json`

```json
{
  "checkIntervalSeconds": 30,
  "reportCommand": "reportlist",
  "minPjAdvantage": 1,
  "playSound": true
}
```

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `checkIntervalSeconds` | `30` | Интервал проверки в секундах |
| `reportCommand` | `"reportlist"` | Команда для открытия меню |
| `minPjAdvantage` | `1` | Минимальный перевес ПЖ над ЛЖ |
| `playSound` | `true` | Звук при обнаружении репорта |

## Установка

1. Скачай `.jar` из [Releases](../../releases) или из [Actions](../../actions)
2. Положи в папку `.minecraft/mods/`
3. Нужен [Fabric Loader](https://fabricmc.net/) + [Fabric API](https://modrinth.com/mod/fabric-api)

## Сборка

```bash
./gradlew build
```

JAR будет в `build/libs/reportwatcher-1.0.0.jar`

## GitHub Actions

При каждом push в `main` автоматически собирается JAR и прикрепляется к workflow run.
